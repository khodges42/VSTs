# EIS skin provenance

The silver/red chrome-and-plastic interface and pixel steak are original,
code-drawn graphics in `plugins/eis/src/editor.rs`. No downloaded bitmap,
Winamp skin, proprietary plugin graphics or third-party steak icon is used.
The small marbled steak is a separate pixel grid function, independent of
labels, meters and control hit regions. Original graphics use the source license.

Fonts come from the pinned egui default-font package; their original notices
are retained by the bundle's third-party license collector. A future skin can
replace the palette/header/icon while retaining the functional widgets.
